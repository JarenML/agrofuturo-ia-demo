# AGROFUTURO IA — Demo conceptual

Página ilustrativa para presentar la idea de AGROFUTURO IA ante autoridades.
**Todo es simulado:** no hay IA, ni WhatsApp, ni backend, ni base de datos.

## Cómo abrirla

```bash
npm install
npm run dev
```

Luego abra la dirección que muestra la terminal (por defecto http://localhost:5173).

## Cómo presentarla

- **Siguiente paso** avanza la historia de Rosa (10 pasos, unos 2 minutos).
- También se avanza con los botones del chat y con el botón **Validar** del técnico.
- **Reiniciar** vuelve al inicio.
- Atajos de teclado: flecha derecha o barra espaciadora para avanzar, tecla R para reiniciar.
- En el primer paso, los otros 5 módulos del menú responden con un mensaje de ejemplo.

## Cambiar los textos

Toda la historia, los módulos, los casos y los indicadores están en `src/data/guion.ts`.
Se pueden editar sin tocar los componentes.
